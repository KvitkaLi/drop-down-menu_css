# Пояснення для учнів:
- **position: absolute** дозволяє розташувати підменю відносно позиціонованого батьківського елемента;  
- top: 100% розміщує підменю нижче батьківського пункту;  
- left: 0 вирівнює його за лівим краєм;  
- :hover реагує на наведення миші;  
- :focus-within дає змогу показувати підменю, коли фокус клавіатури перебуває на посиланні всередині батьківського пункту;  
- :focus-visible допомагає користувачу бачити, який елемент зараз активний.  
Важливо: це покращує доступність для клавіатури, але ще не робить меню повністю адаптивним для мобільних пристроїв. Для сенсорного керування може знадобитися окреме рішення.  
### Пояснення наступного коду:  
.menu > li:hover > .menu__submenu,  
.menu > li:focus-within > .menu__submenu {  
display: block;  
}  
1. **:hover** — відкриття мишкою  
   .menu > li:hover > .menu__submenu {   
    display: block;  
Псевдоклас :hover спрацьовує, коли курсор миші перебуває над пунктом меню <li>. Тоді вкладене підменю .menu__submenu стає видимим.   
Це звична поведінка для випадаючих меню.  

2. **:focus-within** — відкриття з клавіатури  
   .menu > li:focus-within > .menu__submenu {    
    display: block;  
  }  
Псевдоклас :focus-within спрацьовує, коли сам елемент або будь-який його вкладений елемент отримує фокус.  
Наприклад, користувач натискає клавішу Tab і переходить до посилання в пункті меню.  
Якщо це посилання розташоване всередині відповідного <li>, підменю може відкритися без використання миші.  
Це важливо для доступності сайту.
