# Drop-down Menu — випадаюче меню на HTML та CSS

## 📌 Про проєкт

Цей навчальний проєкт демонструє створення випадаючого меню навігації за допомогою HTML і CSS без використання JavaScript.

Меню містить основні пункти навігації, а один із них — **«Цікаві факти»** — відкриває підменю під час наведення курсора. Такий спосіб організації навігації дає змогу розмістити більше посилань, не перевантажуючи сторінку.

## 🎯 Мета проєкту

Навчитися створювати випадаючі меню та зрозуміти, як HTML і CSS взаємодіють під час побудови елементів навігації вебсайту.

## 🛠️ Використані технології

- **HTML5** — створення структури меню за допомогою елементів `<nav>`, `<ul>` та `<li>`.
- **CSS3** — оформлення пунктів меню, керування розташуванням і відображенням підменю.
- **CSS `:hover`** — показ підменю під час наведення курсора.
- **CSS `position`** — позиціювання підменю відносно батьківського пункту навігації.
- **CSS `display`** — керування видимістю елементів меню.

## 📚 Чого можна навчитися

Працюючи з проєктом, можна навчитися:

- будувати вкладену структуру списків для створення навігації;
- використовувати вкладені елементи `<ul>` і `<li>`;
- працювати з властивостями CSS `position` та `display`;
- створювати інтерактивні ефекти за допомогою псевдокласу `:hover`;
- розуміти принцип роботи випадаючого підменю;
- відокремлювати HTML-структуру від CSS-оформлення.

## 💡 Для кого цей проєкт?

Проєкт призначений для початківців, які вивчають HTML і CSS, та може використовуватися як навчальний приклад на заняттях із веброзробки.

## 🚀 Як переглянути проєкт

1. Відкрийте репозиторій на GitHub.
2. Завантажте файли проєкту або клонуйте репозиторій.
3. Відкрийте HTML-файл у браузері.
4. Наведіть курсор на пункт меню «Цікаві факти», щоб побачити випадаюче підменю.

## ✏️ Ідеї для вдосконалення

- Додати плавну анімацію появи підменю.
- Оформити активні та наведені пункти меню.
- Реалізувати підтримку клавіатурної навігації.
- Перевірити коректну роботу меню на мобільних пристроях.
